# Datos de prueba del software clínico (MOCK)

Estos archivos son **ficticios**. Se usan solo cuando la clínica no tiene configurada una integración real
(proveedor `mock`). No corresponden a personas reales: los RUT son valores de prueba conocidos
(11.111.111-1, 22.222.222-2, …) y los correos usan el dominio reservado `example.com`.

No agregue datos reales de pacientes en esta carpeta.
